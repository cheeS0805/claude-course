# Міні-проєкт модуля 6. Трекер звичок v1

**Мета:** спершу спроєктувати дані на папері, потім написати чотири функції, які з ними працюють, і перевірити їх сценарієм.

## Що вміє трекер v1

- Людина веде кілька звичок: «Читати 20 хв», «Зарядка».
- Звичку можна додати. Порожня назва і назва, яка вже є, не додаються; «Читати 20 хв» і « читати 20 ХВ » — одна й та сама звичка.
- Звичку можна відмітити в певний день (дні поки — числа). Відмітити той самий день двічі — не помилка, нічого не змінюється.
- Трекер рахує поточну серію: скільки днів поспіль звичку виконано.

---

## 1. Модель даних на папері

- **Одна звичка** — запис з двома полями: назва і дні, коли її виконано.
- **Дні — список номерів, а не лічильник.** Лічильник «виконано 4 рази» не показує, чи дні йшли поспіль: у дні 1, 2, 3, 4 серія на день 4 — 4, а в дні 1, 5, 9, 20 — 0, хоча лічильник однаковий. Зі списку видно і кількість (`done.length`), і серію.
- **Багато звичок — список записів.** Звичок 5–10, тому перебір списку — непомітна мить, а ясність важливіша за швидкість. До запису легко додати нове поле (мету, колір) — у словнику «назва → дні» довелося б переробляти всю структуру.

```
habits ──► [ 0 , 1 ]
             │   └──► { name: "Зарядка",      done: ──► [ 4, 5 ] }
             └──────► { name: "Читати 20 хв", done: ──► [ 1, 2, 3, 5 ] }
```

## 2. Модель курсу

```js
const habits = [
  { name: "Читати 20 хв", done: [1, 2, 3, 5] },
  { name: "Зарядка", done: [4, 5] },
];
```

| Поле | Що це | Приклад |
|---|---|---|
| `name` | назва звички так, як її ввела людина, без пробілів по краях | `"Читати 20 хв"` |
| `done` | список номерів днів, коли звичку виконано, без повторів | `[1, 2, 3, 5]` |

Моя модель збіглася з моделлю курсу. Спершу я думала зберігати лічильник виконань; список днів зручніший — з нього рахується і кількість, і серія.

## 3–6. Чотири функції

```js
// Контракт findHabit(habits, name)
// Приймає: habits — список звичок, name — назва (будь-який регістр, пробіли по краях)
// Повертає: сам об'єкт звички зі списку (не копію) або null, якщо такої немає
// Обіцяє: нічого не друкує і не змінює
function findHabit(habits, name) {
  name = name.trim().toLowerCase();
  for (const habit of habits) {
    if (habit.name.trim().toLowerCase() === name) {
      return habit;
    }
  }
  return null;
}

// Контракт addHabit(habits, name)
// Приймає: habits — список звичок, name — назва від людини
// Повертає: true, якщо звичку додано; false, якщо назва порожня або така звичка вже є
// Змінює: дописує { name, done: [] } у habits; назву зберігає без пробілів по краях,
//         регістр — як ввела людина
function addHabit(habits, name) {
  name = name.trim();
  if (name === "") {
    return false;
  }
  if (findHabit(habits, name) !== null) {
    return false;
  }
  habits.push({ name: name, done: [] });
  return true;
}

// Контракт markDone(habits, name, day)
// Приймає: habits — список звичок, name — назва (будь-який регістр), day — номер дня
// Повертає: true, якщо звичку знайдено; false, якщо такої немає
// Змінює: додає day у done звички, якщо його там ще немає (без повторів)
function markDone(habits, name, day) {
  const habit = findHabit(habits, name);
  if (habit === null) {
    return false;
  }
  if (!habit.done.includes(day)) {
    habit.done.push(day);
  }
  return true;
}

// Контракт currentStreak(habit, today)
// Приймає: habit — одна звичка { name, done }, today — номер сьогоднішнього дня
// Повертає: скільки днів поспіль звичку виконано, закінчуючи сьогодні;
//           якщо сьогодні ще не відмічено — серію, що закінчилась учора
// Обіцяє: нічого не друкує і не змінює
function currentStreak(habit, today) {
  let day = today;
  if (!habit.done.includes(day)) {
    day = day - 1;
  }
  let streak = 0;
  while (habit.done.includes(day)) {
    streak = streak + 1;
    day = day - 1;
  }
  return streak;
}
```

- `addHabit` і `markDone` шукають звичку через `findHabit`, а не новим циклом.
- `markDone` відмічає день лише раз: `includes` перед `push`.

### Перевірки окремих функцій

| Виклик | Результат |
|---|---|
| `findHabit(habits, "Зарядка")` | `{ name: "Зарядка", done: [4, 5] }` |
| `findHabit(habits, "  читати 20 ХВ ")` | `{ name: "Читати 20 хв", done: [1, 2, 3, 5] }` |
| `findHabit(habits, "Біг")` | `null` |
| `addHabit` «Читати 20 хв», «Зарядка», « читати 20 ХВ », «  » | `true`, `true`, `false`, `false` |
| `markDone` «зарядка» 4, «Зарядка» 5, «Зарядка» 5, «Біг» 1; потім `done` | `true`, `true`, `true`, `false`; `[4, 5]` |
| `currentStreak` для `done = [1, 2, 3, 5]`, today 5 / 6 / 4 / 7 | `1`, `1`, `3`, `0` |

### План `currentStreak` словами

1. Почати з дня `today`; якщо його немає в `done` — почати з `today - 1` (день ще не скінчився).
2. Серія = 0.
3. Поки поточний день є в `done`: серія + 1, перейти на день назад.
4. Повернути серію.

**Три питання циклу:** починаємо з `day` (сьогодні або вчора) і `streak = 0`; завжди правда — `streak` дорівнює кількості вже порахованих днів поспіль; цикл закінчиться, бо `day` щоразу зменшується на 1, а днів у `done` скінченна кількість.

### Таблиця трасування для `today = 4`, `done = [1, 2, 3, 5]`

| Крок | day | Є в done? | streak |
|---|---|---|---|
| старт | 4 | ні → day = 3 | 0 |
| 1 | 3 | так | 1 |
| 2 | 2 | так | 2 |
| 3 | 1 | так | 3 |
| 4 | 0 | ні → стоп | **3** |

### Для `today = 6`

На день 6 галочки немає — починаємо з 5. День 5 є → серія 1; день 4 немає → стоп. Серія = 1.

## 7. Сценарій

```js
const habits = [];
console.log(addHabit(habits, "Читати 20 хв"));
console.log(addHabit(habits, "Зарядка"));
console.log(addHabit(habits, "  читати 20 ХВ "));
console.log(addHabit(habits, "   "));
for (const day of [1, 2, 3, 5]) {
  markDone(habits, "Читати 20 хв", day);
}
markDone(habits, "зарядка", 4);
markDone(habits, "Зарядка", 5);
markDone(habits, "Зарядка", 5);
console.log(markDone(habits, "Біг", 1));
for (const today of [4, 5, 6, 7]) {
  console.log(`День ${today}:`);
  for (const habit of habits) {
    console.log(`  ${habit.name}: серія ${currentStreak(habit, today)}, усього ${habit.done.length}`);
  }
}
```

## 8. Перевірки поза сценарієм

```js
console.log(currentStreak({ name: "Біг", done: [] }, 1));
const test = [];
addHabit(test, "Біг");
markDone(test, "Біг", 1);
markDone(test, "Біг", 1);
markDone(test, "Біг", 1);
console.log(test[0].done.length);
console.log(findHabit(habits, " зАрЯдКа") === habits[1]);
```

| Перевірка | Результат |
|---|---|
| `currentStreak` з порожнім `done`, today = 1 | `0` — цикл не робить жодного кроку |
| той самий день відмічено тричі | довжина `done` — `1` |
| `findHabit(habits, " зАрЯдКа")` | `true` — повертає той самий об'єкт, що в списку (у Python Tutor стрілки ведуть до однієї коробки), а не копію і не назву |

## 9. Крок до архітектури

### А. Хто знає, як влаштовані дані

| Частина | Знає про `name` | Знає про `done` | Знає, що «вчора» = день − 1 |
|---|---|---|---|
| `findHabit` | так | ні | ні |
| `addHabit` | так (створює запис) | так (створює `done: []`) | ні |
| `markDone` | ні (пошук робить `findHabit`) | так | ні |
| `currentStreak` | ні | так | так |
| сценарій | так (друкує назву) | так (`done.length`) | ні |

### Б. Дні стануть датами

У модулі 12 у `done` лежатимуть рядки на кшталт `"2026-10-14"`.

- Зламається лише `currentStreak`, рядок `day = day - 1`. Решта працює: `includes` і `push` однаково приймають числа й рядки.
- **JavaScript:** `"2026-10-14" - 1` — мінус пробує перетворити рядок на число, з дефісами не виходить — `NaN`. `NaN` немає серед дат, цикл не виконається, функція мовчки поверне неправильну серію без жодної помилки.
- **Python:** `"2026-10-14" - 1` одразу падає з `TypeError` і показує рядок — «падати рано» (урок 6.1), баг видно відразу.

### В. Одне місце для «попереднього дня»

```
// Контракт previousDay(day)
// Приймає: day — день (зараз номер, у модулі 12 — дата-рядок)
// Повертає: попередній день у тому самому форматі
// Обіцяє: нічого не друкує і не змінює
```

`currentStreak` викликає `previousDay(day)` замість `day - 1`. Зараз усередині — `return day - 1`; у модулі 12 переписується лише ця функція.

### Г. Нова вимога: мета — скільки разів на тиждень

- **Змінюються:** `addHabit` (створює запис — додає поле `goal`) і звіт у сценарії (показує мету); рахунок «скільки разів цього тижня» — нова окрема функція.
- **Не змінюються:** `findHabit` (працює лише з `name`), `markDone` і `currentStreak` (працюють лише з `done`).

**Висновок:** що менше частин знають про формат даних, то дешевше його змінити.
