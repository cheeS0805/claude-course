# Міні-проєкт модуля 5. Квиток у кіно 2.0

**Мета:** зібрати касу кінотеатру з маленьких функцій, у кожної з яких є написаний контракт і свої перевірки. У модулі 3 «Квиток у кіно» був одним суцільним шматком умов — тепер програма складається з частин.

## Правила кінотеатру

- **Вік.** Діти до 6 років (0–5) — безкоштовно, і жодні доплати до них не застосовуються. Від 6 до 17 років — 90 грн. Від 18 років — 150 грн.
- **Студентський квиток** діє від 18 років: 100 грн замість 150. Дітям 6–17 він нічого не змінює.
- **Вихідні** (субота, неділя): +30 грн до платного квитка.
- **Вечірній сеанс** (початок о 18:00 або пізніше): +20 грн до платного квитка.
- **Дані.** Вік — ціле число від 0 до 120. День — один із рядків «пн», «вт», «ср», «чт», «пт», «сб», «нд». Сеанси щогодини з 9:00 до 23:00, тож година — ціле число від 9 до 23. На неправильні дані каса не рахує ціну, а пояснює, що не так.

## 2. Дерево функцій

```
sellTicket()                              питає і друкує — єдиний «брудний край»
├── inputProblem(age, day, hour)          текст проблеми або ""
│   └── isValidDay(day)                   чи день один із "пн" … "нд"
├── ticketPrice(age, day, hour, isStudent) ціна квитка
│   ├── basePrice(age, isStudent)         0 / 90 / 100 / 150
│   ├── isWeekend(day)                    субота чи неділя
│   └── isEvening(hour)                   з 18:00
└── ticketText(day, hour, price)          рядок квитка
```

Усі функції, крім `sellTicket`, чисті: нічого не друкують, не питають і не чіпають зовнішніх змінних (константи лише читаються). У контракті «Приймає» чесно написано, які дані функція вважає вже перевіреними: ціну рахують тільки після `inputProblem`.

## 3. Код (функції з контрактами, перевірки, оболонка)

Запускається в консолі браузера (F12 → Console), бо `sellTicket` використовує `prompt`. Перевірки ціни можна запускати і в Python Tutor, якщо прибрати останній рядок `sellTicket();`.

```js
// ---- правила кінотеатру (константи) ----
const FREE_UNDER = 6;
const ADULT_FROM = 18;
const CHILD_PRICE = 90;
const ADULT_PRICE = 150;
const STUDENT_PRICE = 100;
const WEEKEND_FEE = 30;
const EVENING_FROM = 18;
const EVENING_FEE = 20;
const MIN_AGE = 0;
const MAX_AGE = 120;
const FIRST_HOUR = 9;
const LAST_HOUR = 23;
const DAYS = ["пн", "вт", "ср", "чт", "пт", "сб", "нд"];

// Контракт basePrice(age, isStudent)
// Приймає: age — ціле від 0 до 120 (вже перевірене), isStudent — true / false
// Повертає: базову ціну без доплат: 0, 90, 100 або 150
// Обіцяє: нічого не друкує і нічого не змінює
function basePrice(age, isStudent) {
  if (age < FREE_UNDER) {
    return 0;
  }
  if (age < ADULT_FROM) {
    return CHILD_PRICE;
  }
  if (isStudent) {
    return STUDENT_PRICE;
  }
  return ADULT_PRICE;
}

// Контракт isWeekend(day)
// Приймає: day — один із рядків "пн" … "нд" (вже перевірений)
// Повертає: true для "сб" і "нд", інакше false
// Обіцяє: нічого не друкує і нічого не змінює
function isWeekend(day) {
  return day === "сб" || day === "нд";
}

// Контракт isEvening(hour)
// Приймає: hour — ціле від 9 до 23 (вже перевірене)
// Повертає: true, якщо сеанс о 18:00 або пізніше
// Обіцяє: нічого не друкує і нічого не змінює
function isEvening(hour) {
  return hour >= EVENING_FROM;
}

// Контракт ticketPrice(age, day, hour, isStudent)
// Приймає: усі дані вже перевірені inputProblem
// Повертає: ціну квитка в гривнях; безкоштовний квиток — 0, без доплат
// Обіцяє: нічого не друкує і нічого не змінює
function ticketPrice(age, day, hour, isStudent) {
  let price = basePrice(age, isStudent);
  if (price === 0) {
    return 0;
  }
  if (isWeekend(day)) {
    price = price + WEEKEND_FEE;
  }
  if (isEvening(hour)) {
    price = price + EVENING_FEE;
  }
  return price;
}

// Контракт isValidDay(day)
// Приймає: day — будь-яке значення
// Повертає: true, якщо це один із рядків "пн" … "нд"
// Обіцяє: нічого не друкує і нічого не змінює
function isValidDay(day) {
  for (const d of DAYS) {
    if (day === d) {
      return true;
    }
  }
  return false;
}

// Контракт inputProblem(age, day, hour)
// Приймає: будь-які значення (ще не перевірені)
// Повертає: текст першої проблеми або "" — якщо дані правильні
// Обіцяє: нічого не друкує і нічого не змінює
function inputProblem(age, day, hour) {
  if (!Number.isInteger(age) || age < MIN_AGE || age > MAX_AGE) {
    return "Вік має бути цілим числом від 0 до 120";
  }
  if (!isValidDay(day)) {
    return "День має бути одним із: пн, вт, ср, чт, пт, сб, нд";
  }
  if (!Number.isInteger(hour) || hour < FIRST_HOUR || hour > LAST_HOUR) {
    return "Сеанси щогодини з 9:00 до 23:00";
  }
  return "";
}

// Контракт ticketText(day, hour, price)
// Приймає: перевірені день і годину, ціну в гривнях
// Повертає: рядок квитка, наприклад "Квиток: сб, 19:00 — 200 грн"
// Обіцяє: нічого не друкує і нічого не змінює
function ticketText(day, hour, price) {
  return `Квиток: ${day}, ${hour}:00 — ${price} грн`;
}

// ---- перевірки цеглин ----
console.log(isEvening(17) === false, isEvening(18) === true);
console.log(isWeekend("сб") === true, isWeekend("пт") === false);
console.log(basePrice(5, false) === 0, basePrice(6, false) === 90, basePrice(18, true) === 100);
console.log(isValidDay("нд") === true, isValidDay("субота") === false);
console.log(ticketText("сб", 19, 200) === "Квиток: сб, 19:00 — 200 грн");

// ---- таблиця перевірок ціни ----
console.log(ticketPrice(30, "сб", 19, false) === 200);  // приклад з правил
console.log(ticketPrice(5, "пн", 12, false) === 0);     // межа віку 5
console.log(ticketPrice(6, "пн", 12, false) === 90);    // межа віку 6
console.log(ticketPrice(17, "пн", 12, false) === 90);   // межа 17
console.log(ticketPrice(18, "пн", 12, false) === 150);  // межа 18
console.log(ticketPrice(17, "пн", 12, true) === 90);    // студентський у 17 нічого не змінює
console.log(ticketPrice(18, "пн", 12, true) === 100);   // студентський у 18
console.log(ticketPrice(30, "пн", 17, false) === 150);  // 17:00 — ще день
console.log(ticketPrice(30, "пн", 18, false) === 170);  // 18:00 — вечір
console.log(ticketPrice(30, "пт", 12, false) === 150);  // п'ятниця
console.log(ticketPrice(30, "сб", 12, false) === 180);  // субота
console.log(ticketPrice(30, "нд", 12, false) === 180);  // неділя
console.log(ticketPrice(30, "пн", 9, false) === 150);   // перший сеанс
console.log(ticketPrice(30, "пн", 23, false) === 170);  // останній сеанс
console.log(ticketPrice(5, "сб", 20, false) === 0);     // безкоштовна дитина в суботу ввечері
console.log(ticketPrice(20, "нд", 21, true) === 150);   // студент у неділю ввечері: 100 + 30 + 20

// ---- неправильні дані ----
console.log(inputProblem(-1, "пн", 12));
console.log(inputProblem(121, "пн", 12));
console.log(inputProblem(30, "субота", 12));
console.log(inputProblem(30, "пн", 8));
console.log(inputProblem(30, "пн", 24));
console.log(inputProblem(30, "пн", 12) === "");

// Контракт sellTicket()
// Приймає: нічого — питає дані в людини
// Повертає: нічого
// Обіцяє: єдина функція, яка питає і друкує
function sellTicket() {
  const age = Number(prompt("Вік:"));
  const day = prompt("День (пн, вт, ср, чт, пт, сб, нд):");
  const hour = Number(prompt("Година сеансу (9–23):"));
  const isStudent = prompt("Є студентський? (так/ні)") === "так";
  const problem = inputProblem(age, day, hour);
  if (problem !== "") {
    console.log(problem);
    return;
  }
  console.log(ticketText(day, hour, ticketPrice(age, day, hour, isStudent)));
}

sellTicket();
```

## 4. Результат перевірок

- Перевірки цеглин (`isEvening`, `isWeekend`, `basePrice`, `isValidDay`, `ticketText`) — усі `true`.
- Таблиця ціни — 16 рядків, усі `true`, зокрема дорослий у суботу о 19:00 → 200 грн і дитина 5 років у суботу о 20:00 → 0.
- Неправильні дані — кожен рядок отримує своє повідомлення, ціна не рахується.

**Три сценарії `sellTicket`:**

| Ввід | Вивід |
|---|---|
| 30, сб, 19, ні | Квиток: сб, 19:00 — 200 грн |
| 5, сб, 20, ні | Квиток: сб, 20:00 — 0 грн |
| 30, «субота», 19, ні | День має бути одним із: пн, вт, ср, чт, пт, сб, нд |

## 5. Відомий недолік: літери замість віку

`Number("абв")` дає `NaN`. Каса не впала і не продала квиток: `inputProblem` перевіряє `Number.isInteger(age)`, а `NaN` не ціле число, тож людина бачить «Вік має бути цілим числом від 0 до 120». Але є тонше місце: порожній ввід і «Скасувати» `Number` перетворює на 0 — а 0 років проходить перевірку, і каса мовчки продасть безкоштовний дитячий квиток. Для кінотеатру це гірше, ніж каса, яка впала: падіння видно одразу, а неправильну ціну — ні. Правильна обробка вводу — тема модуля 7.

## 6. Нове правило — скільки змін

| Вимога | Які функції зміняться | Чиї контракти зміняться | Нові рядки перевірок | sellTicket? |
|---|---|---|---|---|
| а. «Середа — день кіномана: усі платні квитки на 30 грн дешевші» | `ticketPrice` (нова доплата зі знаком мінус) і нова чиста `isMovieDay(day)` | `ticketPrice` — у «Повертає» нове правило | середа, ціна платного і безкоштовного квитка, четвер для порівняння | ні |
| б. «Відкрився зал IMAX: доплата 60 грн до платного квитка» | `ticketPrice` отримує новий параметр `isImax`; `inputProblem` і `ticketText`, якщо зал треба перевіряти й показувати | `ticketPrice` — новий параметр, тож змінюються **всі її виклики** | IMAX / не IMAX, безкоштовна дитина в IMAX | так — треба спитати, який зал |
| в. «Замість каси квитки продає Telegram-бот» | лише `sellTicket` (замість `prompt` / `console.log` — повідомлення бота) | жодних | жодних — усі старі перевірки працюють як є | так — її замінює бот |

**Своїми словами.** «Правила кінотеатру» — це константи і чисті функції: `basePrice`, `isWeekend`, `isEvening`, `ticketPrice`, `inputProblem`, `isValidDay`, `ticketText`. «Розмова з людиною» — лише `sellTicket`. Завдяки цьому поділу Telegram-бот (в) зачіпає одну функцію, а правила й усі перевірки переходять без змін. Найдорожчою виявилась вимога IMAX (б): функція ціни дізнається про зал лише з нового параметра, а зміна контракту — це зміна в кожному місці, де її викликають. Чим менше функцій зачіпає нова вимога, тим краще програма розкладена.
