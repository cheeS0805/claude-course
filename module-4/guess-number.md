# Міні-проєкт модуля 4. Вгадай число

**Мета:** зібрати все з модулів 2–4 в одну справжню гру — цикл, що гарантовано закінчується, лічильник спроб, умови і ввід від людини, — і вперше відділити правила гри від вводу й виводу.

## Правила гри

- Комп'ютер загадує ціле число від 1 до 100 включно.
- Людина вводить числа; на кожне програма відповідає «загадане число більше», «загадане число менше» або «вгадав».
- У людини 7 спроб. Не вгадала за 7 — програма називає загадане число.
- Число менше за 1 або більше за 100 не рахується як спроба: програма нагадує про межі.
- Наприкінці програма каже, за скільки спроб людина вгадала.

Загадане число — 37.

| Ввід | Ситуація | Відповідь програми | Спроба рахується? | Гра триває? |

| 50 | звичайна спроба | загадане число менше | так | так |

## 2. Версія без вводу (ряд спроб)

```js
// ---- правила гри (налаштування) ----
const MIN = 1;
const MAX = 100;
const MAX_ATTEMPTS = 7;
const secret = 37;

const guesses = [50, 150, 25, 37];   // спроби гравця замість вводу

// ---- ведучий ----
let attempts = 0;
let won = false;
for (const raw of guesses) {
  const guess = Number(raw);

  // ---- правила: спроба → вердикт ----
  let verdict = "";
  if (!Number.isInteger(guess) || guess < MIN || guess > MAX) {
    verdict = "поза межами";
  } else if (guess < secret) {
    verdict = "більше";
  } else if (guess > secret) {
    verdict = "менше";
  } else {
    verdict = "вгадав";
  }

  // ---- ведучий: рахує спробу ----
  if (verdict !== "поза межами") {
    attempts = attempts + 1;
  }

  // ---- вивід ----
  if (verdict === "поза межами") {
    console.log(`${raw}: число має бути від ${MIN} до ${MAX} — спроба не рахується`);
  } else if (verdict === "більше") {
    console.log(`${raw}: загадане число більше`);
  } else if (verdict === "менше") {
    console.log(`${raw}: загадане число менше`);
  } else {
    console.log(`${raw}: вгадав!`);
  }

  // ---- ведучий: чи гра триває ----
  if (verdict === "вгадав") {
    won = true;
    break;
  }
  if (attempts === MAX_ATTEMPTS) {
    break;
  }
}

// ---- вивід результату ----
if (won) {
  console.log(`Перемога за ${attempts} спроб(и)`);
} else if (attempts === MAX_ATTEMPTS) {
  console.log(`Спроби закінчились. Загадане число: ${secret}`);
} else {
  console.log(`Спроби в ряду закінчились, гру не завершено (використано ${attempts} з ${MAX_ATTEMPTS})`);
}
```

| Ряд спроб | Результат |
|---|---|
| [50, 150, 25, 37] | менше, поза межами (не рахується), більше, вгадав — **Перемога за 3 спроби** |
| [1, 2, 3, 4, 5, 6, 7, 8] | сім разів «більше» — **Спроби закінчились. Загадане число: 37**; восьма спроба вже не розглядається |
| [0, 101, −5] | три нагадування про межі, зараховано 0 спроб, гру не завершено |

Для іншого ряду змінюється лише рядок `guesses` — решта програми та сама.

## 4. Справжня гра (ввід у консолі браузера)

Ряду спроб більше немає — скільки разів людина вводитиме число, наперед невідомо, тому `for` замінено на `while`.

```js
// ---- правила гри (налаштування) ----
const MIN = 1;
const MAX = 100;
const MAX_ATTEMPTS = 7;
const secret = Math.floor(Math.random() * 100) + 1;   // крок 5: випадкове число 1–100

// ---- ведучий ----
let attempts = 0;
let won = false;
while (!won && attempts < MAX_ATTEMPTS) {
  // ---- ввід ----
  const raw = prompt(`Спроба ${attempts + 1} з ${MAX_ATTEMPTS}. Твоє число (1–100):`);
  if (raw === null) {
    console.log("Гру скасовано");
    break;
  }
  const guess = Number(raw);

  // ---- правила: спроба → вердикт (символ у символ як у версії 2) ----
  let verdict = "";
  if (!Number.isInteger(guess) || guess < MIN || guess > MAX) {
    verdict = "поза межами";
  } else if (guess < secret) {
    verdict = "більше";
  } else if (guess > secret) {
    verdict = "менше";
  } else {
    verdict = "вгадав";
  }

  // ---- ведучий: рахує спробу ----
  if (verdict !== "поза межами") {
    attempts = attempts + 1;
  }

  // ---- вивід ----
  if (verdict === "поза межами") {
    console.log(`${raw}: число має бути від ${MIN} до ${MAX} — спроба не рахується`);
  } else if (verdict === "більше") {
    console.log(`${raw}: загадане число більше`);
  } else if (verdict === "менше") {
    console.log(`${raw}: загадане число менше`);
  } else {
    console.log(`${raw}: вгадав!`);
    won = true;
  }
}

// ---- вивід результату ----
if (won) {
  console.log(`Перемога за ${attempts} спроб(и)`);
} else if (attempts === MAX_ATTEMPTS) {
  console.log(`Спроби закінчились. Загадане число: ${secret}`);
}
```

**Три питання циклу:**
1. З чого починаємо: `attempts = 0`, `won = false`.
2. Що завжди правда: `attempts` — скільки зарахованих спроб уже було.
3. Чому гра точно закінчиться: кожна зарахована спроба додає 1, і на сьомій умова `attempts < MAX_ATTEMPTS` стає хибною; або людина вгадала (`won = true`), або натиснула «Скасувати» (`break`). Спроби поза межами не зараховуються — гра триває, доки людина вводить неправильні значення, але це рішення людини, а не помилка циклу.

Перевірка з загаданим 37: сім спроб (5, 6, 78, 90, 67, 78, 89) — «Спроби закінчились. Загадане число: 37».

## 5. Випадкове число

`Math.floor(Math.random() * 100) + 1` — `Math.random()` дає дріб від 0 до 1 (1 не входить), множення на 100 — від 0 до 99.99…, `Math.floor` — ціле від 0 до 99, `+ 1` — від 1 до 100.

Перевірка: гра з випадковим числом — сім спроб (6, 78, 56, 25, 67, 8, 9), «Спроби закінчились. Загадане число: 63»; відповіді «більше / менше» на кожну спробу узгоджуються з 63.

Випадковість додано останньою, бо з випадковим числом неможливо перевірити програму: щоразу інша відповідь, і не зрозуміло, чи помилка в коді, чи просто «так випало». Спершу правила перевірено на відомому 37, і лише потім замінено один рядок.

## 6. Нечесний гравець

`Number("абв")` повертає `NaN` («не число»). Будь-яке порівняння з `NaN` — неправда: `NaN < 1` і `NaN > 100` обидва `false`. Тому перевірка лише меж `guess < MIN || guess > MAX` пропустила б «абв», а далі «більше» і «менше» теж неправда — гра сказала б «вгадав!». Виправлення — спершу перевірити, що це ціле число: `!Number.isInteger(guess)` відсіює і `NaN`, і дроби на кшталт 37.5.

## 7. Правила окремо від вводу і виводу

У коді три частини позначено коментарями:
- **правила** — з двох чисел (загадане і спроба) роблять вердикт: «більше», «менше», «вгадав», «поза межами»; ні `prompt`, ні `console.log`;
- **ведучий** — цикл, лічильник спроб і рішення «гра триває чи ні»;
- **ввід і вивід** — звідки береться спроба (ряд або `prompt`) і як вердикт показується людині.

Частина «правила» у версіях 2 і 4 однакова символ у символ.

1. **Гра переїжджає в Telegram-бота.** Змінюються ввід (спроба приходить повідомленням) і вивід (вердикт надсилається в чат). Правила і ведучий лишаються як є.
2. **10 спроб і числа до 1000.** Змінюються два рядки нагорі: `MAX_ATTEMPTS = 10` і `MAX = 1000` (і `* 1000` у випадковому числі). Цикл гарантовано закінчиться так само — на десятій зарахованій спробі. 10 спроб вистачить, бо 1000 ділиться навпіл до 1 за 10 кроків.
3. **Нове правило «гаряче!»** (спроба відрізняється від загаданого не більше ніж на 5). Змінюються правила — новий вердикт — і вивід — нове повідомлення. Ведучий не змінюється.

**Висновок.** Чим менше частин зачіпає нова вимога, тим краще продумана програма. Версія з рядом спроб — зародок автоматичного тесту: вона перевіряє правила без людини за клавіатурою.
