# Міні-проєкт модуля 2. Чек у кав'ярні

**Мета:** зібрати весь модуль в одну програму — ввід, перетворення типів, змінні з гарними іменами, обчислення, гарний вивід і таблицю трасування.

## Що вміє програма

Програма для каси кав'ярні питає назву напою чи страви, ціну за одну штуку в гривнях, кількість штук і знижку у відсотках, а потім друкує чек. Для вводу «Капучино, 55, 3, 10»:

```
------- ЧЕК -------
Капучино x 3 по 55.00 грн
Сума: 165.00 грн
Знижка 10%: 16.50 грн
До сплати: 148.50 грн
-------------------
```

---

## 1. План

| Ввід (змінна, тип) | Обчислення | Вивід |
|---|---|---|
| назва — `itemName`, текст | `subtotalUah` = ціна × кількість | `------- ЧЕК -------` |
| ціна за штуку — `unitPriceUah`, число | `discountUah` = сума × відсоток / 100 | назва x кількість по ціна грн |
| кількість — `quantity`, число | `totalUah` = сума − знижка | Сума / Знижка N% / До сплати |
| знижка — `discountPercent`, число | | `-------------------` |

`prompt` завжди повертає рядок, тому ціну, кількість і знижку одразу перетворюю через `Number`. Назву не перетворюю — з нею нічого не рахують.

## 2. Програма

Запускається в консолі браузера (F12 → Console), бо `prompt` — команда браузера.

```js
// ---- ввід ----
const itemName = prompt("Назва напою чи страви:");
const unitPriceUah = Number(prompt("Ціна за штуку, грн:"));
const quantity = Number(prompt("Кількість:"));
const discountPercent = Number(prompt("Знижка, %:"));

// ---- обчислення ----
const subtotalUah = unitPriceUah * quantity;
const discountUah = subtotalUah * discountPercent / 100;
const totalUah = subtotalUah - discountUah;

// ---- вивід ----
console.log("------- ЧЕК -------");
console.log(`${itemName} x ${quantity} по ${unitPriceUah.toFixed(2)} грн`);
console.log(`Сума: ${subtotalUah.toFixed(2)} грн`);
console.log(`Знижка ${discountPercent}%: ${discountUah.toFixed(2)} грн`);
console.log(`До сплати: ${totalUah.toFixed(2)} грн`);
console.log("-------------------");
```

- Усі `prompt` — лише у вводі, усі `console.log` — лише у виводі, в обчисленні — тільки змінні й арифметика.
- Усі змінні — `const`: жодна не змінюється після створення.
- `toFixed(2)` — лише у виводі: він повертає рядок, рахувати з ним далі не можна.

Для вводу «Капучино, 55, 3, 10» чек збігається зі зразком до символу.

## 3. Трасування

Ввід: «Капучино, 55, 3, 10». Для Python Tutor кожен `prompt(...)` тимчасово замінено рядком (`Number("55")` тощо).

| Рядок | itemName | unitPriceUah | quantity | discountPercent | subtotalUah | discountUah | totalUah |
|---|---|---|---|---|---|---|---|
| 1 | "Капучино" | | | | | | |
| 2 | "Капучино" | 55 | | | | | |
| 3 | "Капучино" | 55 | 3 | | | | |
| 4 | "Капучино" | 55 | 3 | 10 | | | |
| 5 | "Капучино" | 55 | 3 | 10 | 165 | | |
| 6 | "Капучино" | 55 | 3 | 10 | 165 | 16.5 | |
| 7 | "Капучино" | 55 | 3 | 10 | 165 | 16.5 | 148.5 |

Рядки 8–13 нічого не змінюють і друкують шість рядків чека.

## 4. Перевірки

| Ввід | Що надрукувала програма | Чи правильно для кав'ярні | Що мало б статися |
|---|---|---|---|
| Капучино, 55, 3, 10 | 165.00 / 16.50 / 148.50 | так | — |
| кількість 0 | усе 0.00 | ні — чек на нуль чашок | «Кількість має бути від 1» |
| знижка 100 | До сплати: 0.00 | підозріло — безкоштовно | попросити підтвердження або обмежити максимум |
| знижка 150 | Знижка 150%: 247.50, До сплати: −82.50 | ні — кав'ярня винна клієнту | «Знижка має бути від 0 до 100» |
| ціна 45,50 | NaN у всьому чеку | ні | зрозуміти кому або попросити ввести через крапку |
| кількість 2.5 | Сума: 137.50, До сплати: 123.75 | ні — пів капучино | «Кількість — ціле число» |
| порожня назва | « x 3 по 55.00 грн» | ні — чек без назви | «Введіть назву» |
| «Скасувати» на назві | null x 3 по 55.00 грн | ні — слово null у чеку | скасувати весь чек |
| «Скасувати» на ціні | усе 0.00 | ні — безкоштовна кава | скасувати весь чек |

Виправляти поки не треба: перевіряти ввід навчимося в модулях 3 і 7. Кожен поганий рядок — вимога на майбутнє.

## 5. Крок до архітектури: ввід, обчислення, вивід

| Нова вимога | Ввід | Обчислення | Вивід |
|---|---|---|---|
| Чек англійською | — | — | змінюється: тексти рядків чека |
| Ціна з меню, а не від касира | змінюється: замість `prompt` ціна береться з меню | — | — |
| Картка постійного клієнта (ще −5% після звичайної знижки) | змінюється: питання «Є картка?» | змінюється: додаткова знижка | змінюється, якщо показувати знижку за карткою окремим рядком |
| Програма стає Telegram-ботом | змінюється: питання надходять повідомленнями | **не змінюється** | змінюється: чек надсилається в чат |

**Висновок.** Обчислення не залежить від того, звідки прийшли дані і куди піде результат, тому його можна перенести в бота, на сайт чи в касовий апарат без змін. Чим менше блоків зачіпає нова вимога, тим краще продумана програма.

**Другий товар у чеку.** Ввід — ще три питання (назва, ціна, кількість другого товару). Обчислення — сума кожного рядка окремо, загальна сума = рядок 1 + рядок 2, знижка рахується від загальної суми. Вивід — ще один рядок «назва x кількість по ціна грн». Для будь-якої кількості товарів знадобляться цикл і список (модулі 4 і 6).
